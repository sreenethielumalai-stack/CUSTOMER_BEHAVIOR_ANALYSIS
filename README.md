#Project Overview

This project focuses on analyzing e-commerce sales data and customer purchasing behavior to generate meaningful business insights. The analysis explores sales performance, customer segmentation, discount impact, subscription trends, product performance, and revenue distribution.

# Project Objectives
- Understand customer purchasing behavior.
- Identify top-performing products.
- Analyze the impact of discounts on purchases.
- Segment customers based on previous purchases.
- Compare subscribers and non-subscribers.
- Analyze revenue contribution across different age groups.

# Tools & Technologies
- Oracle SQL: Data querying, aggregation, filtering, and customer analysis.
- Python (Google Colab): Data analysis and exploration.
- Power BI: Interactive dashboards and data visualization.
- Dataset: Customer shopping behavior data (CSV).

# Project Files
- Customer shopping dataset (.csv)
- SQL analysis queries (.sql)
- Python analysis notebook (.ipynb)
- Power BI dashboard (.pbix)

# Business Questions Analyzed
1. Which five products have the highest percentage of purchases with discounts?
2. How can customers be segmented into New, Returning, and Loyal customers?
3. What are the top three products in each category?
4. Are repeat buyers more likely to subscribe?
5. What is the revenue contribution of each age group?
6. How does purchasing behavior differ between subscribers and non-subscribers?
7. Which gender contributes the highest revenue?

# Analysis Performed

Oracle SQL
- Customer segmentation.
- Product performance analysis.
- Discount purchase analysis.
- Subscription and repeat purchase analysis.
- Revenue analysis by age group and gender.

Python
- Data analysis using Google Colab.
- Exploring customer shopping behavior.
- Analyzing patterns and trends in the dataset.

Power BI
- Created an interactive customer behavior dashboard.
- Visualized sales and customer insights.
- Presented key business metrics and trends.

#  Key Takeaways
This project demonstrates how SQL, Python, and Power BI can be used together to analyze customer shopping data, identify purchasing patterns, and support data-driven business decisions.
